# Launch retro synthesis

## When to use

- About 30 days have passed since launch and the results sit in exports, feedback files, and half-filled tables.
- You ran several channel tests and need a verdict on each before spending more.
- You need an operating rhythm for the quarter after launch.

## Steps

1. Read [`INDEX.md`](../../../.productmap/INDEX.md), [`gtm-launch.md`](../../../.productmap/02_discovery/marketing/gtm-launch.md), [`metrics-tracking.md`](../../../.productmap/03_analysis/kpis-metrics/metrics-tracking.md), [`analytics.md`](../../../.productmap/03_analysis/analytics/analytics.md), and all files in [`06_data/feedback/`](../../../.productmap/06_data/feedback/) and [`06_data/analytics/`](../../../.productmap/06_data/analytics/).
2. Compare each launch goal with its result. Give every channel test a kill, iterate, or scale verdict using the rule set before launch.
3. Read the funnel stage by stage and group the feedback into themes with quotes and source counts.
4. Save the retro as `.productmap/02_discovery/marketing/launch-retro-YYYY-MM-DD.md` with what to keep feeding, what to stop, and the cadence for the next quarter.

## Delegation

Use [subagent-prompt.md](subagent-prompt.md) for a sub-agent that reads all exports and feedback together and returns the retro.
